# Ferrum Studio

Premium creative agency website — UI/UX design system and React implementation.

- `DESIGN.md` — full UI/UX design system (colors, type, grid, sitemap, page specs)
- `src/App.jsx` — React implementation (Home, Work, Project Detail, Services, About, Contact)

## Stack
Vite + React, inline styles, no external UI library. Internal client-side page-switching (no react-router yet).

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```
